# Twitter / X Clone

A responsive **Twitter/X Clone** built to improve my **web development skills** and get hands-on experience with **Tailwind CSS**.

### 🚀 Tech Stack

* HTML
* JavaScript
* Tailwind CSS

### ✨ Features

* X-like responsive UI
* Sidebar navigation
* Post/feed section
* Trending section
* Who to follow section
* Responsive design
